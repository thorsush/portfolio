# Apple-Style Developer Portfolio

Production-ready one-page portfolio built with Next.js (App Router), Tailwind CSS, and Framer Motion.

## Features

- Dark mode only Apple-inspired UI
- One-page responsive layout
- Animated sections and hover interactions
- GitHub projects loaded from public GitHub API
- Smooth scrolling navigation
- SEO + OpenGraph metadata for social preview
- Security headers in `next.config.js`
- Resume download button (`public/resume.pdf`)

## Setup

1. Install dependencies:
   - `npm install`
2. Copy env template:
   - `cp .env.example .env.local`
3. Set GitHub username in `.env.local`:
   - `NEXT_PUBLIC_GITHUB_USERNAME=your_github_username`
4. Run locally:
   - `npm run dev`

## Build and Deploy

- `npm run build`
- `npm run start`
